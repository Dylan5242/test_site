Модалка «Обратная связь» — (детальное описание)

Здесь подробно описано, как реализована модалка на странице контактов. Рекомендуемый вариант — нативный <dialog>, он даёт модальный режим и фон-подложку через ::backdrop.

Живая демонстрация

Обратная связь (демо)

Короткая аннотация по коду

HTML

Используем <dialog>, внутри — <form method="dialog">. Обязательные атрибуты: aria-labelledby для доступности. Кнопка открытия имеет id="openDialog" и обрабатывается в JS.

CSS (важное)

  • Стили для dialog и dialog::backdrop.
  • Фокусные контуры через :focus-visible.
  • Не используем !important, переопределять — аккуратно через классы.

JS — детали

В main.js реализовано:

  1. Открытие/закрытие модалки (showModal() / close()).
  2. Сохранение предыдущего активного элемента и возврат фокуса после закрытия.
  3. Валидация через Constraint Validation API: checkValidity(), setCustomValidity(), reportValidity().
  4. Лёгкая маска для телефона (ввод цифр → формат +7 (xxx) xxx-xx-xx).

Паттерн телефона

^\+7 \(\d{3}\) \d{3}-\d{2}-\d{2}$

Советы по доступности (A11Y)

  • Всегда используйте aria-labelledby для заголовка диалога.
  • Убедитесь, что фокус удерживается внутри модалки — нативный <dialog> это уже делает в большинстве браузеров.
  • Помечайте проблемные поля aria-invalid="true".

Если <dialog> не поддерживается

Можно реализовать «ручную» модалку: фиксированный контейнер, подложка и управление видимостью классов/атрибутов через JS. В таком варианте надо вручную управлять фокусом и клавишей Escape.

Если нужно — могу добавить вариант B (ручная модалка-fallback) или сделать отдельный CSS-файл для модального окна. Скажите, если хотите fallback или стили под вашу тему.
